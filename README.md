# Lyzr.ai Revamp - Enterprise AI Agent Platform

A modern, high-performance revamp of the Lyzr Enterprise AI Agent Platform landing page built with Next.js (App Router), React 19, TypeScript, Three.js, Motion, and Tailwind CSS.

## 🚀 Features

- **Interactive 3D Control Plane**: Real-time 3D model with rotational scroll synchronization across 7 architectural layers with dynamic SVG leader lines.
- **Enterprise Design System**: High-contrast geometric styling, customized micro-animations, dot-grid textures, and accessible typography.
- **Enterprise Showcase & Ecosystem**: Interactive agent mesh, security & governance controls, and production statistics.
- **Optimized Performance**: Next.js App Router with server-side rendering, code-split components, smooth scroll integration, and responsive layout for desktop, tablet, and mobile.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) & [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.18 or higher recommended)
- npm, yarn, or pnpm

### Installation

1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📦 Available Scripts

- `npm run dev` - Starts the Next.js development server
- `npm run build` - Builds the application for production
- `npm run start` - Runs the built production application
- `npm run lint` - Runs Next.js ESLint checks
